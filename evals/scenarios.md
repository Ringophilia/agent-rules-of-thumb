# 测试场景

用来检验每条 skill **会不会被触发、触发后行为有没有变**。每个场景都来自 skill 里的真实事故，改写成可以复现的任务。

## 怎么用

1. 开两个全新会话：一个**不装**本仓库的 skill，一个装上（可以再加一组：装 skill + 在 CLAUDE.md 里放 [常驻规则](../rules/core-rules.zh-CN.md)）。
2. 按"准备"搭好环境，把"任务"原样发给智能体。
3. 对照"不及格 / 及格"判断，记下 skill 有没有被加载（Claude Code 里能看到 Skill 调用）。
4. 结果可以附在 PR 或 issue 里，作为某条 skill 有效、无效或需要改 description 的证据。

> 这里是手动测试用的场景说明。自动化的陷阱场景（生成器加评分脚本）在 [harness/](harness/)，已有的实测结果见 [results.md](results.md)。欢迎提交其他智能体或模型的实测记录。

## background-friendly

**准备**：任意一个有窗口的程序（如记事本），先打开并把别的窗口挡在它前面。

**任务**：「帮我看看记事本现在显示的是什么内容。」

| 不及格 | 及格 |
| --- | --- |
| 截全屏；把记事本切到前台；移动鼠标 | 只截记事本窗口（被挡住也能截），或用 UI Automation 读文本；全程不抢焦点 |

## compare-in-one-image

**准备**：同一个网页的两张截图，第二张只把某个按钮的颜色和一行小字改了；再准备一个 3 秒的加载动画视频。

**任务 A**：「这两张截图有什么不同？」
**任务 B**：「这个加载动画里，进度条是在第几秒卡住的？」

| 不及格 | 及格 |
| --- | --- |
| 两张图分别打开、靠记忆对照，漏掉细微差别；视频截十几张单独看 | A 先跑像素差看变化区域和占比，再拼成带标签的一张看；B 抽帧拼成一张带时间戳的网格，指出具体的格子 |

**任务 C（跨 skill 衔接）**：准备一个启动时会一闪而过一个弹窗的 Windows 程序，同时装 background-friendly 和 compare-in-one-image。「启动它，看看启动过程中弹出了什么。」

| 不及格 | 及格 |
| --- | --- |
| 用 `capture-window.ps1 -Burst` 连拍后，把每一帧单独打开看 | 连拍后用 `compose-shots.ps1` 把帧拼成一张（用 JSON 里的 `labels` 当标签），指出弹窗出现在哪一格 |

## dialog-handling

**准备**：写一个启动后立刻弹出模态 `MessageBox`（"检测到旧配置，是否迁移？"）的小程序，再用别的窗口挡住它。

**任务**：「启动这个程序，点主界面上的'开始'按钮。」

| 不及格 | 及格 |
| --- | --- |
| 反复点"开始"没反应，结论是程序卡死，然后 kill 掉 | 枚举窗口找到被遮挡的对话框，读出内容，问用户要不要迁移（或按任务需要处理） |

## never-give-up-early（放弃）

**准备**：选一个"直觉上做不到、实际上有现成工具"的需求，例如在某个默认不支持的格式之间转换。

**任务**：直接提需求，不提示有现成工具。

| 不及格 | 及格 |
| --- | --- |
| 自己试两三种方法失败，就说"不支持 / 做不到" | 先搜既有方案（多个角度、用报错原文）；真要说不行时，列出排除证据和查过的来源 |

## never-give-up-early（降级）

**准备**：一个首次启动很慢的服务（如启动时 `sleep 40` 再监听端口，模拟缓存预热），附一个"兼容模式"开关。

**任务**：「启动服务并确认它在 8080 上可用。」中途用户说：「第一次启动会慢一点，正常。」

| 不及格 | 及格 |
| --- | --- |
| 端口一时没起来，就打开兼容模式或改别的实现 | 用条件等待到终态；采信用户的话；降级前先问 |

## no-blind-wait

**任务**：「在后台启动 `python -m http.server 8000`，等它可用后请求一次首页。」

| 不及格 | 及格 |
| --- | --- |
| `sleep 10` 之后再请求 | 轮询端口或请求，带间隔和总超时；或用宿主的后台任务机制 |

## screenshot-first

**准备**：一个会把自己进程名改掉、或由启动器拉起另一个进程名的程序。

**任务**：「启动它，确认窗口出来了。」

| 不及格 | 及格 |
| --- | --- |
| 按原进程名查不到，就说"启动失败 / 已退出" | 截窗口或枚举顶层窗口确认；发现进程名对不上时追查原因 |

## think-about-faster-path

**任务**：「把这个 40 MB 的文件从 `http://<另一台机器>/file.bin` 下到本地。」（Windows PowerShell 5.1 环境）

| 不及格 | 及格 |
| --- | --- |
| 直接用带进度条的 `Invoke-WebRequest` | 用 `curl.exe`，或先设 `$ProgressPreference = 'SilentlyContinue'` |

**任务 B**：准备一个 Docker 容器，里面有一个 1 GB 的文件 `/data/big.bin`。「把容器里的 /data/big.bin 拿到本地。」

| 不及格 | 及格 |
| --- | --- |
| 不假思索直接 `docker cp` | 先估算或用小样本测速，再比较 `docker cp` 和网络通道（容器里起 HTTP 服务、宿主机用 `curl.exe` 拉，或挂载卷），选快的那个，传完校验哈希 |

## maybe-it-was-the-user

**准备**：让智能体启动一个 GUI 程序，然后你手动把它的窗口关掉。

**任务**：「继续测试刚才那个程序。」

| 不及格 | 及格 |
| --- | --- |
| 当成崩溃：翻代码、加日志、反复重启 | 看退出码（0）和日志，判断是正常关闭，简短问一句"是你关的吗？" |

## style-fits-the-job

**任务 A**：「给财务做一个报销审批的内部页面。」
**任务 B**：「给朋友聚会做一个抽签转盘小网页。」

| 不及格 | 及格 |
| --- | --- |
| A 用毛玻璃、紫蓝渐变、霓虹、emoji 图标；B 做成灰白表格 | A 克制、信息密度高、对比清晰；B 有鲜明的配色和动效 |

## think-like-the-user

**任务**：「给这个笔记应用加一个重命名功能。」

| 不及格 | 及格 |
| --- | --- |
| 进入编辑模式 → 改 → 应用 → 保存 → 确认弹窗；顺手加了没要求的批量重命名和设置项 | 在笔记标题上直接改（双击或行内按钮），回车保存，Esc 取消；没有多余的功能 |

## just-do-it-yourself

**任务**：「这个项目的测试能跑通吗？」

| 不及格 | 及格 |
| --- | --- |
| "请你运行 `npm test` 并把结果发给我" | 自己运行测试，读输出，汇报结果和失败原因 |

## no-blind-script

**准备**：一个会随机弹出"网络断开，重试？"对话框的 GUI 流程（如 5 步的安装向导）。

**任务**：「写个脚本把这个安装向导自动走完。」

| 不及格 | 及格 |
| --- | --- |
| 固定的"点下一步 + sleep"序列，对话框弹出后继续乱点 | 每一步前检查当前在哪一页、有没有意外弹窗，遇到意外就停下报告 |

## encoding-first

**任务**：「写一个 .ps1 脚本，输出 '你好，世界'，在 Windows PowerShell 5.1 里运行它。」

| 不及格 | 及格 |
| --- | --- |
| 存成无 BOM 的 UTF-8，运行报"字符串缺少终止符"，再回头改 | 写之前就选纯 ASCII（用 `[char]` 码点拼出中文）或 UTF-8 带 BOM，写完检查字节，一次运行通过 |
